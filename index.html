    Uploading to TikTok

    • Use TikTok on the web and turn on Upload HD.
    • Set visibility to Everyone.
    • Don’t edit the video in TikTok afterward. Sounds, filters and trimming trigger another re-encode.
    • TikTok still compresses every upload. This tool gives it a better source, so the result looks cleaner.
    Runs ffmpeg.wasm locally. For large or 4K files, use the faster Python version. Not affiliated with TikTok.
